A movie club lets members rate films from 1 to 5 stars. Find the club's crowd favorites: movies
with an **average rating of at least 4.0** from **at least 3 ratings**.

Different movies can share a title (remakes happen), so treat each movie `id` separately.

### Output

| column       | description                                     |
| ------------ | ----------------------------------------------- |
| `title`      | the movie's title                               |
| `avg_rating` | its average rating, rounded to 2 decimal places |

Rows can be in any order.
