A small library is taking stock. Count the books in each genre.

Some books haven't been given a genre yet (`genre` is `NULL`). Count those under the genre
`'Uncategorized'`.

### Output

| column       | description                                           |
| ------------ | ----------------------------------------------------- |
| `genre`      | the genre, or `'Uncategorized'` for books without one |
| `book_count` | how many books have that genre                        |

Rows can be in any order.
